# Commit da Turma - SENAI Dev

Bem-vindos ao nosso repositório oficial de memórias! 
Este é o nosso deploy final do 3º ano.

---

## Como participar?

1. Faça um **Fork** deste repositório para a sua conta.
2. Adicione sua foto na pasta `assets/imagens/` (nomeie o arquivo como `seu-nome.jpg` ou `.png`).
3. Na pasta `alunos/`, crie um arquivo chamado `seu-nome.md`.
4. Copie o modelo abaixo, preencha com as suas informações e salve.
5. Abra um **Pull Request** para este repositório original.

---
